Página web que apresenta cinco sites favoritos. Cada item mostra o nome do site, uma imagem e o link para o endereço.

O código executável está disponível em [`index.html`](index.html).

## 🎯 Objetivo

Praticar a estrutura básica de uma página web: título da aba, cabeçalhos, imagens locais, links e organização do conteúdo em listas e cartões.

## 📋 Sites apresentados

| # | Site | Endereço |
| ---: | --- | --- |
| 1 | YouTube | https://www.youtube.com |
| 2 | Crunchyroll | https://www.crunchyroll.com |
| 3 | X | https://x.com |
| 4 | Tudo Celular | https://tudocelular.com |
| 5 | Reddit | https://www.reddit.com |

## 🧠 Conceitos utilizados

- `<title>` para o título que aparece na aba do navegador.
- `<h1>` para o nome de cada site e para o título do corpo da página.
- `<img>` com imagens locais, guardadas na mesma pasta do HTML.
- `<a>` para o link abaixo de cada imagem (e, opcionalmente, na própria imagem).
- Tags semânticas: `<header>`, `<main>`, `<footer>`.
- Lista não ordenada (`<ul>` e `<li>`) para agrupar os cartões.
- CSS em `<style>` com variáveis (`:root`), *flexbox/grid* e responsividade com `minmax`.
- Comentários em várias linhas no HTML e no CSS.

## ▶️ Como executar

É necessário ter Git instalado e um navegador web.

No terminal, baixe o repositório e entre na pasta do projeto:

```bash
git clone https://github.com/Lucaslmx/Ag12_DS_I.git
cd Ag12_DS_I
```

Abra o arquivo `index.html` no navegador (clique duas vezes sobre ele ou arraste para a janela do navegador).
